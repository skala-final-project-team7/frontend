데이터 현황 디자인 시안

"마지막 동기화 + 스페이스 / 페이지 / 첨부파일 / VectorDB / 청크" 를 한눈에 들어오면서도 흔한 대시보드 같지 않게 풀어낸 4가지 방향입니다. 모노스페이스 숫자·하프라인·비대칭으로 손으로 디자인한 느낌을 줍니다.

01

리포트 레저

재무 명세서처럼. 점선 리더(leader)로 라벨↔값을 잇고, 굵은 상단 룰과 모노 숫자로 "문서" 느낌. 스캔이 아주 쉬움.

상업 레퍼런스 — 완전 다른 방향
