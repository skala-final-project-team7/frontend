데이터 수집 상태 UI 시안

GET /api/admin/ingest/status/{jobId} 응답 필드를 그대로 사용합니다. 모달형과 인라인형(버튼 왼쪽 → 진행 오른쪽) 시안을 비교하고, LINA 캐릭터로 진행을 표현한 버전도 포함합니다.

00

상태 & 실제 응답 필드

STARTED IN_PROGRESS COMPLETED FAILED
data: { jobId, status, totalPages, processedPages, failedPages, startedAt }
→ 진행률 = processedPages / totalPages · 실패 = failedPages · 경과 = now − startedAt
01

모달 버전

버튼 → 모달 진행 → COMPLETED 시 닫기(X) 활성화. 3가지 시안.

02

인라인 버전 · 버튼 왼쪽 → 진행 오른쪽

모달 없이 같은 블록 안에서 오른쪽 영역에 진행 과정이 펼쳐집니다. 3가지 시안.

INLINE · A

데이터 파이프라인

Confluence 전체 스페이스를 수집합니다. 진행 상황이 오른쪽에 표시됩니다.

대기 중 — 버튼을 누르면 수집이 시작됩니다.
INLINE · B · LINA

데이터 파이프라인

LINA가 결승점의 깃발을 향해 달려갑니다. 도착하면 수집 완료!

대기 중 — 버튼을 누르면 LINA가 출발합니다.
INLINE · C

데이터 파이프라인

단계형 스텝과 핵심 숫자만 간결하게 보여줍니다.

대기 중 — 수집 단계가 여기에 표시됩니다.
INLINE · D · LINA + 바

데이터 파이프라인

진행바 맨 앞에서 LINA가 슝슝 달리고, 끝나면 깃발을 꽂습니다.

대기 중 — 버튼을 누르면 LINA가 출발합니다.
