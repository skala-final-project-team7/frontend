LINA · Ingestion Pipeline

데이터 수집 상태 UI 시안

GET /api/admin/ingest/status/{jobId} 응답 필드를 그대로 사용합니다. 모달형과 인라인형(버튼 왼쪽 → 진행 오른쪽) 시안을 비교하고, LINA 캐릭터로 진행을 표현한 버전도 포함합니다.

00

상태 & 실제 응답 필드

STARTED IN_PROGRESS COMPLETED FAILED
data: { jobId, status, totalPages, processedPages, failedPages, startedAt }
→ 진행률 = processedPages / totalPages · 실패 = failedPages · 경과 = now − startedAt
01

모달 버전

버튼 → 모달 진행 → COMPLETED 시 닫기(X) 활성화. 3가지 시안.

02

인라인 버전 · 버튼 왼쪽 → 진행 오른쪽

모달 없이 같은 블록 안에서 오른쪽 영역에 진행 과정이 펼쳐집니다. 3가지 시안.

INLINE · A

데이터 파이프라인

Confluence 전체 스페이스를 수집합니다. 진행 상황이 오른쪽에 표시됩니다.

대기 중 — 버튼을 누르면 수집이 시작됩니다.
INLINE · B · LINA

데이터 파이프라인

LINA가 결승점의 깃발을 향해 달려갑니다. 도착하면 수집 완료!

대기 중 — 버튼을 누르면 LINA가 출발합니다.
INLINE · C

데이터 파이프라인

단계형 스텝과 핵심 숫자만 간결하게 보여줍니다.

대기 중 — 수집 단계가 여기에 표시됩니다.
INLINE · D · LINA + 바

데이터 파이프라인

진행바 맨 앞에서 LINA가 슝슝 달리고, 끝나면 깃발을 꽂습니다.

대기 중 — 버튼을 누르면 LINA가 출발합니다.
INLINE · E · 파이프라인

데이터 파이프라인

CI 배포처럼 단계가 흐르고, 가는 그라데이션 바로 진행률을 표시합니다.

대기 중 — 수집 단계가 순서대로 흐릅니다.
INLINE · F · 메트릭

데이터 파이프라인

핵심 지표 타일과 % 내장 그라데이션 바. 실시간 ETA까지 표시합니다.

대기 중 — 지표가 채워집니다.
INLINE · G · 게이지

데이터 파이프라인

코닉 그라데이션 도넛 게이지와 상세 항목을 함께 보여줍니다.

대기 중 — 게이지가 차오릅니다.
INLINE · H · 스트라이프

데이터 파이프라인

흐르는 스트라이프 + 글로우 바. 처리율(pages/s)과 ETA를 강조합니다.

대기 중 — 버튼을 누르면 흐릅니다.
INLINE · I · 터미널

데이터 파이프라인

CI 빌드 로그처럼 처리 과정이 콘솔에 스트리밍됩니다.

대기 중 — 콘솔에 로그가 흐릅니다.
INLINE · J · 세그먼트

데이터 파이프라인

성공 / 실패 / 남음을 한 줄 스택 바로 나눠 보여줍니다(용량 바 스타일).

대기 중 — 성공·실패·남음 비율이 채워집니다.
INLINE · K · 링

데이터 파이프라인

그라데이션 액티비티 링과 핵심 수치를 나란히 보여줍니다.

대기 중 — 링이 차오릅니다.
INLINE · L · 라이브 차트

데이터 파이프라인

수집량 추이를 실시간 영역 차트로 그립니다(폴링마다 점 추가).

대기 중 — 추이 그래프가 그려집니다.
INLINE · M · ETA 버블

데이터 파이프라인

진행바 끝에 % 버블이 함께 달리고, 아래에 ETA를 표시합니다.

대기 중 — 버블이 바를 따라 달립니다.
INLINE · N · 히어로

데이터 파이프라인

큰 진행률 숫자와 남은 시간(ETA)을 강조한 에디토리얼 레이아웃.

대기 중 — 진행률과 ETA가 표시됩니다.
INLINE · O · 리퀴드

데이터 파이프라인

물결치며 차오르는 리퀴드 게이지. 부드럽고 감각적인 느낌.

대기 중 — 게이지가 물결치며 차오릅니다.
INLINE · P · 소프트

데이터 파이프라인

상태에 따라 은은하게 변하는 그라데이션 카드 + 글래스 바.

대기 중 — 카드가 은은하게 채워집니다.
