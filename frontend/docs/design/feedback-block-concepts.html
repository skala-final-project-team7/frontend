긍정/부정 비율 + 피드백 추이 디자인 컨셉

레퍼런스(시간대별 접속 추이)의 따뜻한 오렌지 무드를 기준으로 3가지 방향을 제안합니다. 성공/에러용 시맨틱 컬러(초록·빨강) 대신 브랜드 오렌지 = 긍정, 차분한 슬레이트 = 부정으로 "관리 지표" 톤을 통일하는 것이 공통 원칙입니다.

A

Warm Glow — 게이지 도넛 + 그라데이션 라인

레퍼런스 이미지와 가장 가까운 방향. 추이는 스택 바 대신 긍정 라인+면 그라데이션으로 흐름을 보여주고, 부정은 가는 점선 라인으로 보조 표기합니다. 비율 카드는 얇은 링 게이지 중앙에 큰 % 숫자를 둡니다.

C

Diverging — 반원 게이지 + 미러 바

긍정은 기준선 위(오렌지), 부정은 기준선 아래(딥 웜그레이)로 대칭 분기시켜 "부정이 늘어난 날"이 시각적으로 가장 강하게 드러나는 관리자 친화 구성입니다. 비율은 반원 게이지로 압축합니다.
